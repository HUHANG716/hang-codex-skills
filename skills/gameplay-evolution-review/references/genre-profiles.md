# Genre Profiles

Use the profile that best matches the game. If the game is a hybrid, combine only the relevant checks.

## Puzzle

- Evidence: solve rate, move count, hint usage, dead states, branching factor, first-error point, reset count.
- Watch for: hidden irreversible mistakes, unclear objective, accidental brute force, misleading affordances, difficulty spikes.
- Scenarios: first-time solve, inefficient solve, near-solution mistake, hint-assisted solve, impossible/dead-state probe.

## Action Or Arcade

- Evidence: time-to-kill, damage taken, deaths, input windows, cooldown use, enemy pressure, readability failures, recovery time.
- Watch for: unreadable hazards, unfair spawn timing, dominant kiting, unavoidable damage, control latency, sensory overload.
- Scenarios: low-skill survival, intended aggressive play, cautious play, high-skill route, stress wave/boss route.

## RPG Or Roguelike

- Evidence: build path, encounter outcomes, attrition, loot quality, power spikes, death causes, run variance, healing economy.
- Watch for: early unavoidable death, one solved build, dead traits/items, runaway scaling, weak recovery paths, overly punitive variance.
- Scenarios: safe build, risky build, random build, optimizer build, bad loot seed, high-roll seed, late-game stress.

## Strategy, Tactics, Or 4X

- Evidence: resource curve, unit trades, map control, expansion rate, tech timing, action economy, counterplay, snowball point.
- Watch for: first-player advantage, irreversible early lead, dominant tech path, stale openings, no comeback window, hidden information mismatch.
- Scenarios: turtle, rush, economy boom, balanced play, suboptimal opening, optimized opening, long-game stalemate.

## Card Or Board Game

- Evidence: draw variance, hand quality, tempo, dominant combos, first-player advantage, stalemate routes, deck/build diversity.
- Watch for: non-games from bad draws, infinite combos, no counterplay, unclear timing windows, runaway leader, solved opening.
- Scenarios: weak draw, strong draw, intended combo, control/stall, aggro/rush, mirror/fairness test.

## Idle Or Incremental

- Evidence: time-to-upgrade, compounding rate, wait walls, reset/prestige value, automation unlock timing, offline gain.
- Watch for: dead waiting, exponential runaway, mandatory spam clicks, misleading upgrade value, prestige trap, no new decisions after automation.
- Scenarios: no-action baseline, active play, optimized upgrade order, early prestige, delayed prestige, long-run inflation.

## Narrative Or Social Simulation

- Evidence: choice visibility, state flags, consequence timing, branch convergence, relationship changes, world consistency.
- Watch for: false choices, hidden state surprise without foreshadowing, incoherent character reaction, delayed consequence with no memory cue.
- Scenarios: honest route, hostile route, mixed route, edge-case flags, repeated choice pressure, branch convergence check.

## Multiplayer Or Live Game

- Evidence: matchmaking quality, queue/session length, role balance, economy inflation, grief routes, churn moments, win-rate spread.
- Watch for: pay-to-win pressure, dominant role/class, griefing without counterplay, collusion, smurf incentives, reward inflation.
- Scenarios: new player, veteran optimizer, underdog comeback, coordinated group, exploit/grief route, economy long-run route.

## Gamified Product Or Learning Game

- Evidence: task completion, learning signal, repetition fatigue, reward clarity, progress persistence, error recovery.
- Watch for: points replacing understanding, reward farming, unclear transfer to real task, shame loops, inaccessible feedback.
- Scenarios: first task, repeated task, wrong answer recovery, reward optimization, skipped learning path.
